Build and publish an original, playable single-page browser game named "Hamster Pacer: Echo" for the Squeekchain Genesis Code lane. The player traces the real speed curves of Squeektoshi's hamster-wheel runs by tapping a tempo. It is NOT a falling-notes rhythm game, not a lane game, not a dashboard. English UI, static site on IPFS, source repo with README.

Data (public, CORS enabled; verify every field name against the live responses, never invent endpoints or values) • GET https://api.squeekchain.com/v1/measurement/runs for recorded runs (start time, duration, RPM or speed samples). • GET https://api.squeekchain.com/v1/status every 5 seconds for live state: measurement.coreStatus (ACTIVE / IDLE / COUNTER_FAULT), measurement.rpmMilli / 1000, measurement.freshness, builder.projected.blockHeight (fall back to builder.anchor). • If a source is unavailable, say so in the UI and disable the modes that need it. Never show simulated data as real.

Core mechanic: tempo tracing • Each recorded run becomes a "track": its RPM over time is drawn as a glowing curve scrolling right to left across a seismograph-style canvas, compressed to 45 to 90 seconds of play. • The player taps (Space, or a large pad on mobile) to set a tempo. Player RPM is computed from a rolling 3-second window of taps and drawn as a second line. • Score each frame by how close the two lines are: within 8% = gold, within 20% = silver, else miss. Holding gold builds a Flow multiplier (x1 to x5). When the real curve drops to 0 (he paused mid-run), the player must stop tapping; tapping during his pause costs Flow. • End screen: accuracy %, longest gold streak, Flow peak, and the real run's facts (date, length, top RPM).

Modes • Daily Track: the longest completed run from the previous UTC day, so everyone plays the same track. Shows "Pacer #". • Share card: a Wordle-style emoji grid (10 squares, gold/silver/miss per segment) plus score, copied to clipboard with one button, ready to post on X. No links to wallets. • Setlist: browse the last 20 recorded runs as tracks, sorted by date, each with a mini sparkline of its curve and the player's best grade. • Live Duet: only while the wheel is ACTIVE. The curve is drawn in real time from /v1/status and the player paces him as it happens. Each new Squeek block during the duet adds a +250 x Flow bonus with a toast naming the real block number. • Lullaby: while the wheel is IDLE, Live Duet is replaced by a calm screen with a moon and a breathing circle; staying quiet for 60 seconds earns a "Good roommate" sticker for the collection. His rest is never punished or rushed.

Progress • Sticker collection (10 stickers: first gold run, 5-day Daily streak, 100% on a track, a Duet over 2 minutes, Lullaby, and others) saved in localStorage. • Local best per track and Daily streak counter. Player name max 20 chars, escaped.

Presentation • Retro oscilloscope look mixed with cozy hamster pixel art: dark warm brown background, amber and mint lines, small animated wheel in the corner spinning at the live RPM. • First-visit tutorial overlay of 3 short cards. Mobile and desktop friendly, reduced-motion option, sound toggle with a soft tick per tap.

Rules • No token, no wallet connect, no contracts, no betting, no prizes. • Footer: unofficial fan game for Squeekchain; data read live from the public API on Sepolia testnet.
