The whole request

MNEMO. Tagline: "Your AI's memory, sealed on chain".

Token: name "Mnemo", symbol "MNEMO", fixed supply, plain transfers, no tax, no mint. The launch pool pairs MNEMO with IMD.

What it is

Your AI remembers you, and so does whoever runs its servers. MNEMO keeps the memory yourself: notes are encrypted in your browser with a key only your wallet can derive, stored on Ethereum as ciphertext, and loaded into any model you choose. Switch from Claude to GPT to a local model and your AI still knows you. Nobody else can read a word. Every note you seal burns MNEMO.

What each contract does

MnemoVault stores sealed notes as events, burns the stamp, tracks each wallet's key epoch, and records which agent wallets a user has granted access to. No contract ever sees plaintext or keys.

Who can call what

Anyone with MNEMO: write(bytes[] notes, uint32 epoch) for their own vault.

A note's owner: forget(uint256[] ids), rotate().

A vault owner: grant(address agent, bytes sealedKey), revoke(address agent). revoke also rotates the owner's epoch.

A granted agent: writeFor(address owner, bytes[] notes, uint32 epoch), paying the stamp from its own MNEMO.

Anyone: register(bytes32 x25519PublicKey) so others can grant it access.

Owner (launch owner, Ownable2Step, renounce disabled): setStamp(uint256) within 100 to 100,000 MNEMO per note, for future writes only. No pause, no upgrade, no other powers.

Numbers the contracts enforce

Stamp: 2,000 MNEMO per note at launch, sent to 0x000000000000000000000000000000000000dEaD in the same call.

A note is at most 2,048 bytes; at most 16 notes per call; epoch must equal the writer's current epoch for that vault.

Note ids count up per contract from 1. Events: Noted(owner, id, epoch, ciphertext), Forgotten(owner, id), Rotated(owner, epoch), Granted(owner, agent, epoch, sealedKey), Revoked(owner, agent), KeyRegistered(account, key), StampChanged(old, new).

Views: epochOf(owner), isGranted(owner, agent), notesTotal(), burnedTotal().

Outside services and values

None on chain. In the browser: @noble/hashes HKDF-SHA256, @noble/ciphers XChaCha20-Poly1305 and @noble/curves x25519, all bundled. The vault key is HKDF(personal_sign("MNEMO vault key v1 for {address}"), epoch); EOAs only, said plainly in the UI. Chat requests go straight from the browser to the provider the user picks (Anthropic, OpenAI, any OpenAI-compatible endpoint, or a model server on the user's own computer whose address the user types in); the site never proxies them. The site ships no private or local addresses of its own.

What the site shows

Static IPFS site, label mnemo, title "MNEMO", public RPCs with fallback, no backend, no analytics, every script and font bundled.

Home: the tagline, one line under it, "Open your vault", and one canvas centrepiece: drifting dots that gather into a sealed capsule when the vault opens.

Chat: provider picker, API key kept in memory unless the user ticks "Remember on this device", the conversation, and a side panel "What MNEMO remembers" with the decrypted notes. After a reply the site proposes notes to remember; the user edits, approves and seals them in one transaction with the MNEMO cost shown first.

Agents: register a key, grant or revoke an agent wallet, and docs with llms.txt plus a 40-line script that reads and writes a vault.

Numbers: network totals only (notes sealed, MNEMO burned, vaults opened). Never list other wallets or their notes.

FAQ: what is on chain (ciphertext only), who sees prompts (the provider you pick, nobody with a local model), what forget and rotate do (old ciphertext stays on chain but rotation makes later notes unreadable to revoked agents), EOAs only.

What a connected wallet can do

Open the vault with one signature, chat, seal, edit, forget and rotate notes, grant and revoke agents, buy and sell MNEMO in the launch pool, and export its decrypted notes as a JSON file.

Look and feel

Light sky paper #E9F1F7, ink #0F1A26, one signal accent #FF5B2E. Newsreader for headlines, Spline Sans Mono for everything else. Square buttons with a hard 2px ink shadow, no gradients, no glow, no pills. Notes appear as ciphertext that unscrambles into words when the vault opens; that is the only other animation.
