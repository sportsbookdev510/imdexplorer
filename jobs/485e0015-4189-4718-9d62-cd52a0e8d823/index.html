HAMSTER FRIENDSHIP — COMPLETE FIX & FINAL IMPROVEMENT

IMPORTANT: Update the EXISTING Hamster Friendship project. Do NOT rebuild from scratch, create a duplicate project, or remove existing working features.

Audit the entire project, fix the following issues, and verify everything on the actual production website.

1. CLOUD SAVE & SUPABASE — CRITICAL

The website currently displays: "Cloud saves are not available on this site yet. Guest play is ready."

Fix the underlying production configuration.

  • Identify and connect the correct production Supabase backend.
  • Apply all required database migrations.
  • Enable persistent player profiles linked to verified wallet addresses.
  • Save and restore player progress, SQK balances, inventory, purchases and lifetime scores.
  • Preserve data across sessions, devices and wallet reconnections.
  • Keep Guest Play available with separate guest and wallet profiles.
  • Prevent duplicate profiles and accidental data overwrites.
  • Display clear errors when cloud storage is unavailable.

Do not simply hide the warning or replace cloud storage with localStorage.

2. LIFETIME TOP 100 — REMOVE DAILY RESET

Replace the existing Daily Top 100 system completely.

The current interface incorrectly displays:

  • Daily Top 100
  • Best map score earned today
  • A new day clears the ranking
  • Daily rankings are unavailable until cloud saves are enabled.

New requirements:

  • Rename it to Lifetime Top 100.
  • Rank players by their accumulated lifetime score across all sessions.
  • Never reset, clear, expire or delete lifetime scores.
  • Store scores permanently in Supabase.
  • Update rankings continuously.
  • Only verified wallet profiles can appear on the leaderboard.
  • Guests remain unranked.
  • Preserve all existing historical scores where available.
  • Never fabricate historical scores.

Separate:

  • Current Map Score: score earned in the current game session.
  • Lifetime Score: cumulative score from all completed sessions.

Remove all daily reset logic, scheduled resets and related UI messages.

3. MOBILE LANDSCAPE & METAMASK

Fix the mobile experience, especially when using MetaMask Mobile.

Issue A — MetaMask Mobile:

  • The game does not properly rotate to landscape after connecting a wallet.
  • Detect device orientation.
  • Request landscape orientation when supported.
  • If orientation locking is unavailable, show a clear rotate-device overlay.
  • Preserve wallet connection and game session during orientation changes.

Issue B — iPhone Safari:

  • The game does not use the full available screen because browser address and navigation bars remain visible.
  • Use 100dvh, 100dvw and VisualViewport API.
  • Handle safe-area insets.
  • Remove unnecessary page margins, padding and scrolling.
  • Resize the game dynamically when browser toolbars appear or disappear.
  • Add a user-triggered fullscreen option where supported.
  • Support standalone PWA / Add to Home Screen for a more immersive iPhone experience.
  • Respect iOS Safari browser limitations.

Issue C — Accidental zoom:

  • Prevent accidental double-tap zoom during gameplay.
  • Use touch-action: manipulation on appropriate controls.
  • Prevent unintended multi-tap gestures.
  • Keep joystick, attack, jump and other controls responsive to repeated touches.
  • Maintain accessibility and avoid unnecessarily disabling pinch zoom across the entire website.

Do not stretch pixel art or distort the game canvas.
