CREATE. create(amount, slots, lucky, keyAddress, salt, duration, revealCommit) pulls amount IMD from the creator. 0.5% of amount is sent to 0x000000000000000000000000000000000000dEaD (burned); the rest is the packet. Limits: 1 to 200 slots; every slot gets at least 0.01 IMD; duration 10 minutes to 7 days. Packet ids count up from 1.

PASSPHRASE = KEY. The creator picks a passphrase (口令). The site derives a private key from it: key = keccak256("imd-hongbao" ‖ chainId ‖ HongbaoBox address ‖ salt ‖ passphrase) reduced into the secp256k1 range; keyAddress is that key's address and salt is a random bytes32 chosen by the site. Both are stored in the packet. The passphrase itself never goes on chain.

GRAB. grab(id, recipient, signature) succeeds when the signature is an EIP-712 signature by keyAddress over Grab(uint256 id, address recipient) (domain: name "IMD Hongbao", version "1", chainId, verifyingContract). Anyone may submit it, so a friend or a relayer can pay the gas, but the IMD only ever goes to recipient. Copying a signature from someone else's transaction is useless because it names their recipient. One grab per recipient per packet; no grabs after expiry or once all slots are taken.

EQUAL packets (lucky = false) pay each grabber amount/slots immediately (the last slot takes the rounding remainder).

LUCKY packets (lucky = true, 拼手气) pay nothing at grab time; they record the grabbers in order. Amounts are drawn when the creator opens the packet: reveal(id, secret) with keccak256(secret) == revealCommit, allowed once every slot is taken or the packet has expired. seed = keccak256(secret, id, all grabber addresses in order). Shares use the double-average method: each share except the last is uniform in [0.01 IMD, 2 × remaining / remainingSlots], the last takes the rest; shares only over the slots actually grabbed, scaled to amount × grabbed / slots. reveal() pays every grabber in the same transaction, records the largest share as 手气最佳 (best luck), and refunds the ungrabbed part to the creator. If the creator has not revealed within 24 hours after the packet filled or expired, anyone may call settle(id): equal split among grabbers, ungrabbed part refunded to the creator. Document plainly that the creator can choose between revealing and letting settle() split equally, and that Robinhood Chain's sequencer orders transactions.

REFUND. For equal packets, after expiry anyone may call refund(id), which sends the ungrabbed IMD to the creator. Every packet ends in exactly one terminal state and the contract never holds IMD that no one can withdraw.

VIEWS AND EVENTS. packet(id) returns creator, amount, slots, grabbed count, lucky, expiry, keyAddress, salt, state; grabbers(id) returns addresses and shares (shares 0 until revealed for lucky packets); events PacketCreated, Grabbed, Revealed (with best-luck address), Settled, Refunded.

/// Minimal ERC-20 modelling the live IMD token (0x5f7bb59365ce557c26dbcaa4ee9d39a4b95b7127 on
/// chain 4663), whose transfers revert with "BridgedFP: blocked" when the owner has blocked `to`.
contract BlocklistIMD {
    string public constant name = "Identity.md";
    string public constant symbol = "IMD";
    uint8 public constant decimals = 18;
    uint256 public totalSupply;
    mapping(address => uint256) public balanceOf;
    mapping(address => mapping(address => uint256)) public allowance;
    mapping(address => bool) public blocked;

    function mint(address to, uint256 amount) external {
        totalSupply += amount;
        balanceOf[to] += amount;
    }

    function setBlocked(address account, bool value) external {
        blocked[account] = value;
    }

    function approve(address spender, uint256 amount) external returns (bool) {
        allowance[msg.sender][spender] = amount;
        return true;
    }

    function transfer(address to, uint256 amount) external returns (bool) {
        _move(msg.sender, to, amount);
        return true;
    }

    function transferFrom(address from, address to, uint256 amount) external returns (bool) {
        uint256 a = allowance[from][msg.sender];
        if (a != type(uint256).max) allowance[from][msg.sender] = a - amount;
        _move(from, to, amount);
        return true;
    }

    function _move(address from, address to, uint256 amount) private {
        require(!blocked[from] && !blocked[to], "BridgedFP: blocked");
        require(to != address(0), "ERC20InvalidReceiver");
        balanceOf[from] -= amount;
        balanceOf[to] += amount;
    }
}
