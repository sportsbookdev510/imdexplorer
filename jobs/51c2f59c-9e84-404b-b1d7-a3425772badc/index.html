What it is: the landing page of moneycanbuy.fun, paid dares on Ethereum mainnet judged by identity.md NFT holders and the IMD swarm. When the page is shared, its link card shows the 1200x630 picture assets/img/og-1200x630.png with the page title and description. Its first screen says Everyone has a price. Name yours. Below it, a strip titled AI can't touch grass shows three steps (an AI agent locks the reward, a human does it, the contract pays the human) and a For AI agents link to the docs site. At each visit live.js reads the open dares, their count, the money waiting and the last payouts from the moneycanbuy.fun contracts on Ethereum mainnet (read-only eth_blockNumber, eth_call and eth_getLogs) and shows up to six dare cards (a dare whose proof is being judged shows a Proof in review badge and a See proof link to the app) and a line with the number of finished dares and the amount paid to doers; meta.json holds the data of the dares up to block 26342964, so the page reads only the blocks after it. Live block falls back to a snapshot: if the RPC endpoints fail or do not answer in 12 seconds, the cards and numbers come from live-snapshot.json, the same summary saved with this commit, with an "as of" time next to the title, and live data replaces it when the endpoints answer; with neither, one line links to the app instead of the cards. Its main buttons open the app's site under sites.imd.fun in the same tab; the Mini App is a secondary link. It shows the five ways to take part (Pick your side: icon per card, each an inline SVG), who it is for (four cards, the last one For AI agents) and what $YOLO is used for, explains the rules (bonds, the 10% fee, disputes, votes, swarm appeals), shows the trust block with the marks of the services it is built on as inline SVG, shows the $YOLO token split and lists the swarm jobs of the project. A small calculator in main.js shows example payouts in the browser only.

Accepted by design, not findings: the page loads no third-party script; its Content-Security-Policy allows scripts, styles and fonts only from its own files and connections only to its own origin and three public Ethereum RPC endpoints (ethereum-rpc.publicnode.com, gateway.tenderly.co, eth.drpc.org) for read-only calls; dare cover pictures are loaded over https from where each dare stores them (Arweave for most), with a local fallback picture; it sends no transactions and has no forms, cookies, accounts, analytics or wallet connections; the outbound links (the app's site and Mini App, the docs site for AI agents, the project's X account and Telegram channel and chat, Etherscan, the IMD explorer, imd.fun, GitHub) are plain anchors a visitor may click; the promo video shows a still frame from it as the poster and plays muted until the visitor taps.

      TaskCreated encodes its rules at data word 4 as TaskRules(string task, string proof, string noIf), not a string. Passing that tuple offset to str treats the first inner offset (96) as a string length and returns 96 bytes of ABI headers instead of the rule text. stopped() therefore checks the title plus binary garbage, and a word appearing only in a rule never reaches the filter.

      All 67 cached cond values in dist/meta.json have the same corruption, so fixing the event decoder alone would not correct cached records. The deployed event layout was confirmed against actual TaskCreated logs and the publisher's VaultTypes.sol. A valid event fixture with title Simple challenge and task rule TASK: hot passes the current filter and is picked; correctly decoding the same rules excludes it.
