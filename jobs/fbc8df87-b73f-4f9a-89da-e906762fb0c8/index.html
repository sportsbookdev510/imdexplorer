PROJECT

Hamster Road Trip is a community game. The real Squeekchain hamster's wheel distance moves a marker across a world map, starting at Miami Beach, Florida. The community votes on where the hamster travels next. The hamster does the walking and the community chooses the route.

HOW THE GAME WORKS

  1. The game runs in 24-hour epochs. During an epoch, each wallet votes once for one destination from a fixed list of 64 destinations (ids 0 to 63).
  2. When an epoch ends, the destination with the most votes wins (ties go to the lowest id) and is added to the end of the route queue.
  3. The marker travels to the first destination in the queue, then the next, and so on. Progress is driven only by the hamster: distance travelled = real wheel km x SCALE, where SCALE is one config value (default 100) shown on screen.
  4. If the queue is empty or the wheel is idle, the hamster rests (sleeping animation and a short story line) and waits.
  5. Arriving at a stop shows a postcard: place name, a one-line fun fact and a pixel-art icon. Every arrival is added to a trip log.
  6. A Navigator leaderboard ranks wallets by how many of their votes matched winning destinations.

CONTRACT: RoadTripVotes (Sepolia)

Constructor takes epochSeconds (86400) and destinationCount (64). vote(destinationId): one vote per wallet per epoch, rejects ids out of range. finalize(epoch): callable by anyone once the epoch has ended, records the winner once. Views: currentEpoch, votesFor(epoch, id), winnerOf(epoch), hasVoted(epoch, wallet). Events for votes and finalization. No owner, admin, upgrade path, token or payments. Foundry tests, and an independent review of the contract before deployment.

WEBSITE (static, no backend)

  • Reads the deployed contract address and ABI from the deployment config.
  • Distance is read in the browser from the public Squeekchain API (https://docs.squeekchain.com/developers/api/). Confirm exact endpoints from those docs and do not guess. The solid marker uses settled work only. Optionally show a faint ghost marker for provisional progress. Handle API failures gracefully.
  • Map: Leaflet or MapLibre with an open tile provider (not the openstreetmap.org tile servers), with attribution shown. Routes come from a free open routing service and are cached in the browser. Where no road route exists (oceans), draw a great-circle arc with a ship or plane icon.
  • Destinations: 64 family-friendly places worldwide, mixing nearby and overseas, in a static data file with id, name, coordinates and one fun fact. Facts must be original or properly credited.
  • Voting: wallet connect, choose a destination, send the vote. Show the epoch countdown, live vote counts, the route queue, the trip log and the leaderboard. Voting costs Sepolia test ETH, so link to a public Sepolia faucet. No free-text player input anywhere.
  • The site also works read-only without a wallet (watch the marker, see votes).

import {RoadTripVotes} from "src/RoadTripVotes.sol";

contract RouteOrderTest is Test {
    uint256 internal constant DAY = 86_400;
    RoadTripVotes internal votes;

    function setUp() public {
        vm.warp(1_800_000_000 - (1_800_000_000 % DAY));
        votes = new RoadTripVotes(DAY, 64);

    ///      decide which of them the hamster visits first: the queue follows the order the epochs ended in.

        votes.vote(10);
        vm.warp(block.timestamp + DAY);
        vm.prank(address(0xB0B));
        votes.vote(20);
        vm.warp(block.timestamp + DAY);

        if (!votes.isFinalized(e0 + 1)) votes.finalize(e0 + 1);

        assertEq(votes.routeAt(0).destinationId, 10);
        assertEq(votes.routeAt(1).epoch, e0 + 1);
        assertEq(votes.routeAt(1).destinationId, 20);
