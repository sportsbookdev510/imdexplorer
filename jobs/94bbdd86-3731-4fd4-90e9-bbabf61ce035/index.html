Build and deploy Squeek Boss Raid, a fully playable community boss-raid game and stream companion for Squeekchain Genesis Code (https://squeekchain.com/genesis/code).

A live raid settled on Squeektoshi's real wheel work. Each one-hour season (six 600-second rounds) has a boss whose HP falls only when measured Squeekchain work units increase. Players join with a wallet message signature (no gas to play), pick Tank / Runner / Cheerleader, cheer for score boosts, and climb a local season leaderboard. Include an OBS-friendly overlay at ?mode=overlay.

Must use live Squeekchain: poll https://api.squeekchain.com/v1/status about every 2s with ETag/If-None-Match; show IDLE/ACTIVE, RPM (rpmMilli/1000), round freshness; treat status unavailable as unknown, never as zero. Boss damage = increase in measured cumulativeWorkUnits during the season (document the formula). Optional Sepolia Ping SQK approve(self, 0) only if address is from official docs sepolia.json.

Deliver a production static SPA (base './'), public HTTPS site via IMD hosting, public source repo, README + short English blurb for Genesis, mobile + desktop dark arcade UI. No private keys; no custodial wallets; API for display/game state only. Do not build read-only dashboards, landing pages, thin API wrappers, or copies of existing Genesis projects.
